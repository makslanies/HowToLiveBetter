# Skill «Жизненные решения» (life-decision-guide-ru)

Помогает ИИ-ассистенту отвечать на конкретные вопросы по «Руководству по жизни с высокой отдачей»: стоит ли, выгодно ли, как выбрать, что делать в первую очередь, на какие выплаты можно рассчитывать, не нарушает ли это закон.

Делает он одно: **сначала находит в тексте книги нужные пункты, потом отвечает, расставляя их так, как принято в книге**, и для каждого называет раздел и номер. Если в книге ничего нет, говорит об этом и не выдумывает числа.

Книга китайская: законы, органы, выплаты и телефоны в её пунктах относятся к КНР. Skill обязан прямо говорить об этом тем, кто живёт не в Китае, и опираться на строку «В России:» там, где она есть. Подробности в [SKILL.md](SKILL.md).

Все правила лежат в [SKILL.md](SKILL.md), для двух инструментов используется один и тот же файл.

Рядом лежит [исходный skill на китайском](../life-decision-guide/README.md): он работает с китайским текстом оригинала. Для русского читателя нужен именно этот.

## Установка в Claude Code

Если вы открыли Claude Code в этом репозитории, ставить ничего не нужно: `.claude/skills/life-decision-guide-ru/` уже указывает на эти правила.

Чтобы skill работал в любой папке, скопируйте его в личную папку skills:

```bash
mkdir -p ~/.claude/skills/life-decision-guide-ru && curl -fsSL -o ~/.claude/skills/life-decision-guide-ru/SKILL.md "https://raw.githubusercontent.com/makslanies/HowToLiveBetter/main/skills/life-decision-guide-ru/SKILL.md"
```

После этого достаточно спросить, например, «стоит ли ездить на работу два часа в каждую сторону» или «друг просит стать его поручителем, подписывать ли». Можно и явно сказать: «ответь через life-decision-guide-ru».

## Установка в Codex

В этом репозитории Codex подхватит правила сам: корневой `AGENTS.md` ссылается на них. Чтобы работать в любой папке, скопируйте файл в личную папку skills Codex, `~/.agents/skills`:

```bash
mkdir -p ~/.agents/skills/life-decision-guide-ru && curl -fsSL -o ~/.agents/skills/life-decision-guide-ru/SKILL.md "https://raw.githubusercontent.com/makslanies/HowToLiveBetter/main/skills/life-decision-guide-ru/SKILL.md"
```

Дальше достаточно задать вопрос, skill включится по описанию. Вызвать его явно можно командой `$life-decision-guide-ru`, именно со знаком `$`, а не `/`: новые версии Codex на `/life-decision-guide-ru` отвечают `Unrecognized command`. Если команды нет в списке, перезапустите Codex.

В старых версиях Codex skills нет, там помогают только собственные промпты: положите файл в `~/.codex/prompts/life-decision-guide-ru.md` и вызывайте `/life-decision-guide-ru`. Codex объявил такой способ устаревшим ([openai/codex#10848](https://github.com/openai/codex/issues/10848)), в новых версиях пользуйтесь установкой выше.

## Откуда берётся текст книги

Если репозиторий лежит у вас локально, skill читает `ru/book/`. Если нет, он скачивает текст:

```bash
git clone --depth 1 https://github.com/makslanies/HowToLiveBetter.git "${TMPDIR:-/tmp}/hltb"
```

Вся книга весит около 4 МБ, поверхностный клон занимает несколько секунд. Если сеть недоступна, skill честно говорит, что текста нет, и не подменяет его собственными словами.

## Для тех, кто правит skill

В SKILL.md нет списков и чисел, которые уходят вместе с текстом. Перечень разделов он берёт из таблицы «Какие вопросы разбирает книга» в `ru/README.md`, а правило уровней выгодности из двух строк `COST_W` и `e.ratio` в `ru/index.html`. Поэтому добавление и удаление разделов и смена правил в самой книге этот каталог не меняют.
