# AGENTS.md

Это русская версия китайской книги «高性价比人生指南» («Руководство по жизни с высокой отдачей»). Репозиторий: https://github.com/makslanies/HowToLiveBetter, сайт: https://makslanies.github.io/HowToLiveBetter/. Оригинал: https://github.com/eternity4719/HowToLiveBetter.

**Перед любой правкой прочитайте [CLAUDE.md](CLAUDE.md) целиком.** Имя файла историческое, правила не привязаны к конкретному инструменту. Ниже только самое важное.

## Три правила, которые нельзя нарушать

1. **Китайское и российское не смешивать.** Книга про Китай. Российские сведения пишутся отдельными полями «(Россия)» со своими источниками. Нельзя переносить китайскую норму на Россию.
2. **Ничего не выдумывать.** Каждый российский факт опирается на дословную цитату (до 40 слов) с официальной страницы, каждое число есть в цитате. Нет цитаты, нет факта. Источники только официальные сайты и справочные базы закона (`consultant.ru`, `garant.ru` с пометкой).
3. **Перед завершением запустить тесты:** `node --test tools/ru/country-fields.test.mjs tools/ru/prices.test.mjs`. Сборку (`node tools/ru/build.mjs`, несколько минут) дождаться до конца, тесты читают `dist-ru/site`. Заодно `node tools/ru/validate.mjs`: ожидается 0 ошибок.

- `ru/index.html`, `README.md` (корневой) **генерируются** (`tools/ru/build-index.mjs`, `tools/ru/readme-root.mjs`). Правьте генераторы, не результат.

## Как добавлять российский слой

План запросов → пакет (`tools/ru/evidence.mjs`, срезAI) → черновик (`tools/ru/freedraft.mjs --provider codex`) → проверка (`tools/ru/draft.mjs` без `--apply`) → **прочитать текст самому** и отобрать → `--apply` для отобранных → `apply-overlay.mjs` → `analog.mjs`, `materials.mjs`, `library.mjs` → `validate.mjs` → сборка → тесты → коммит.
Отбрасывать: тексты «в источниках не указано», узкие региональные данные, страницы не по теме, утверждения, которых нет в цитатах.
Метки для пунктов без российского слоя: «Российского аналога нет» (только для чисто китайских систем, после ручной проверки), «Искали, не нашли» (искали, не нашли; не значит, что аналога нет), «Не проверено». Про искавшийся пункт «аналога нет» не писать.

## Стиль текста

Простой русский язык, предложение до 30 слов, у каждого предложения подлежащее. Без «следует», «осуществляется», «в рамках». Без оборотов ИИ («стоит отметить», «важно понимать», итоговая мораль). Суммы без разделителей тысяч; шестизначные: «около 1 млн рублей (1130040 рублей)». «Простыми словами» повторяет только то, что есть в «Выгоде». Числа и годы в «Выгоде» китайских пунктов не менять.

## Секреты и внешние сервисы

- Ключи в `.env` и `commanding-way-*.json` (оба в `.gitignore`). Не печатать значения, не делать `source .env`: читайте скриптом, печатайте только имена и длину.
- Во внешние сервисы отправлять только публичный текст. OpenAI API не работает, его скрипты не запускать. Квота срезAI дневная (журнал `ru-work/research/usage.json`), при ответе 429 остановиться. Лимиты Codex и agy могут быть исчерпаны: зависший `codex exec` остановить.
- Публикации в соцсетях, письма, переобход и отправка карт сайта в Яндекс и Google делаются только по прямой просьбе.
